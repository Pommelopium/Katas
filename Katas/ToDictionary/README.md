# Kata 01_12 — ToDictionary

**Function Kata** aus dem [CCD Coding Dojo](https://ccd-school.de/coding-dojo/) | [Original-Aufgabenstellung](https://ccd-school.de/coding-dojo/function-katas/todictionary/)

## Ziel

Eine Funktion entwickeln, die einen speziell formatierten String analysiert und in ein Dictionary aus String-Schluesseln und String-Werten umwandelt.

## Anforderungen

- Signatur: `IDictionary<string, string> ToDictionary(string input)`
- Das genaue Eingabeformat muss aus der Beispieltabelle auf der Kata-Seite abgeleitet werden
- Randfaelle definieren: leerer Input, doppelte Schluessel, fehlende Werte

## Beispiele und Testfaelle

- Die Beispieltabelle liegt auf der Kata-Seite als Grafik vor -- vor dem Start dort nachschlagen

---

Arbeitsweise: Testfaelle zuerst, dann die Implementierung. Die Kata ist fertig, wenn die
Beispiele oben als automatisierte Tests gruen sind -- nicht, wenn die Konsolenausgabe stimmt.
