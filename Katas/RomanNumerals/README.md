# Kata 01_07 — From Roman Numerals

**Function Kata** aus dem [CCD Coding Dojo](https://ccd-school.de/coding-dojo/) | [Original-Aufgabenstellung](https://ccd-school.de/coding-dojo/function-katas/from-roman-numerals/)

## Ziel

Eine Funktion entwickeln, die roemische Zahlen in Dezimalzahlen konvertiert.

## Anforderungen

- Umwandlung von roemischen Ziffern im Bereich I bis MMM ins Dezimalsystem
- Annahme: die Eingabedaten sind syntaktisch korrekt

## Beispiele und Testfaelle

- `I` -> 1
- `II` -> 2
- `IV` -> 4
- `V` -> 5
- `IX` -> 9
- `XLII` -> 42
- `XCIX` -> 99
- `MMXIII` -> 2013

## Variationen und Randbedingungen

- Erkennung syntaktischer und semantischer Fehler (Ziffernvorrat pruefen, Subtraktionsregel pruefen)
