# Kata 01_04 — Froehliche Zahlen

**Function Kata** aus dem [CCD Coding Dojo](https://ccd-school.de/coding-dojo/) | [Original-Aufgabenstellung](https://ccd-school.de/coding-dojo/function-katas/froehliche-zahlen/)

## Ziel

Eine Funktion entwickeln, die ermittelt, ob eine Zahl froehlich ist: wiederholt die Summe der Quadrate ihrer Ziffern bilden, bis 1 herauskommt.

## Anforderungen

- Iteratives Verfahren: Quadrate der Ziffern summieren und wiederholen
- Endlosschleifen erkennen (Zahlen, die nie bei 1 landen)

## Beispiele und Testfaelle

- 19: 1^2 + 9^2 = 82 -> 8^2 + 2^2 = 68 -> 6^2 + 8^2 = 100 -> 1^2 + 0^2 + 0^2 = 1 -> froehlich

## Variationen und Randbedingungen

- Alle froehlichen Zahlen in einem definierten Bereich identifizieren
