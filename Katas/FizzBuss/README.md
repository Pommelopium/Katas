# Kata 01_03 — FizzBuzz

**Function Kata** aus dem [CCD Coding Dojo](https://ccd-school.de/coding-dojo/) | [Original-Aufgabenstellung](https://ccd-school.de/coding-dojo/function-katas/fizzbuzz/)

## Ziel

Eine Funktion schreiben, die die Zahlen von 1 bis 100 ausgibt und bestimmte Zahlen durch Woerter ersetzt.

## Anforderungen

- Vielfache von 3 -> `Fizz`
- Vielfache von 5 -> `Buzz`
- Vielfache von 3 und 5 -> `FizzBuzz`

## Beispiele und Testfaelle

- 1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz, 16, ...

## Variationen und Randbedingungen

- `Fizz` auch, wenn die Ziffer 3 im Zahlenwert vorkommt (z. B. 13); `Buzz` auch bei der Ziffer 5 (z. B. 52)
