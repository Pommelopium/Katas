# Kata 01_10 — Tannenbaum

**Function Kata** aus dem [CCD Coding Dojo](https://ccd-school.de/coding-dojo/) | [Original-Aufgabenstellung](https://ccd-school.de/coding-dojo/function-katas/tannenbaum/)

## Ziel

Eine Funktion entwickeln, die abhaengig von einer Hoehenangabe einen Tannenbaum als ASCII-Art zurueckgibt.

## Anforderungen

- Die Hoehe wird als Parameter uebergeben
- Der Baum besteht aus `X`-Zeichen, pyramidal angeordnet
- Der Stamm wird durch ein `I` dargestellt

## Beispiele und Testfaelle

Hoehe 5:
```
    X
   XXX
  XXXXX
 XXXXXXX
XXXXXXXXX
    I
```

## Variationen und Randbedingungen

- Einen Stern `*` als Baumspitze ergaenzen
