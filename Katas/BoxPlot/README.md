# Kata 02_03 — Box Plot

**Class Kata** aus dem [CCD Coding Dojo](https://ccd-school.de/coding-dojo/) | [Original-Aufgabenstellung](https://ccd-school.de/coding-dojo/class-katas/box-plot/)

## Ziel

Ein grafisches Steuerelement entwickeln, das Box Plots fuer Zahlenreihen darstellt und damit einen schnellen statistischen Ueberblick ermoeglicht.

## Anforderungen

- Fuenf Kennwerte berechnen und darstellen: Minimum, unteres Quartil, Median, oberes Quartil, Maximum
- Median korrekt ermitteln: mittlerer Wert bzw. Mittelwert der beiden mittleren Werte bei gerader Anzahl
- Quartile durch Teilung der sortierten Liste mit entsprechender Mittelwertbildung bestimmen
- Eigenschaft `Orientation` fuer horizontale oder vertikale Anzeige

## Beispiele und Testfaelle

- Die Kennwertberechnung laesst sich unabhaengig von der Darstellung testen -- genau dort liegt der Trennschnitt, den diese Kata ueben soll

---

Arbeitsweise: Testfaelle zuerst, dann die Implementierung. Die Kata ist fertig, wenn die
Beispiele oben als automatisierte Tests gruen sind -- nicht, wenn die Konsolenausgabe stimmt.
