# Kata 06_02 — Hexdump

**Refactoring Kata** aus dem [CCD Coding Dojo](https://ccd-school.de/coding-dojo/) | [Original-Aufgabenstellung](https://ccd-school.de/downloads/codingdojo/Refactoring%20Kata%20-%20Hexdump.pdf)

## Ziel

Ein vorgegebenes Hexdump-Programm refaktorieren. Die Aufgabenstellung liegt als PDF vor (Link oben).

## Anforderungen

- PDF herunterladen und den Ausgangscode uebernehmen
- Vor jedem Eingriff Characterization Tests schreiben, die das aktuelle Ausgabeformat festnageln
- Dann in kleinen Schritten refaktorieren, nach jedem Schritt Tests laufen lassen

---

Arbeitsweise: Testfaelle zuerst, dann die Implementierung. Die Kata ist fertig, wenn die
Beispiele oben als automatisierte Tests gruen sind -- nicht, wenn die Konsolenausgabe stimmt.

Siehe auch: [KATA-ROADMAP.md](../../KATA-ROADMAP.md) fuer die empfohlene Lernreihenfolge.
